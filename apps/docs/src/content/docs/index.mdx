## Jak to działa w czterech zdaniach

<CardGrid>
  <Card title="Model mówi, świat woła tagiem" icon="comment">
    Sim pisze tekst, który od razu leci do UI i syntezy mowy. Gdy potrzebuje świata, kończy odpowiedź blokiem
    [`<nativeapi>`](/contracts/nativeapi/) — direct call albo plan z zależnościami.
  </Card>
  <Card title="Chat i agent to osobne procesy" icon="setting">
    Chat trzyma rozmowy, simy i głos. Agent wstaje leniwie, wykonuje taski i nadaje eventy. Może chodzić na hoście
    albo w Dockerze.
  </Card>
  <Card title="Wszystko jest eventem" icon="random">
    Jedna koperta [`AgentEvent`](/events/) płynie od capability do karty w czacie, widgetu i bazy. Historia
    odtwarza się po reloadzie.
  </Card>
  <Card title="Sim to folder" icon="document">
    `agents/<name>/`: [manifest](/contracts/agent-manifest/), persona, skille, pamięć i własne pluginy. Simy rozmawiają
    w jednej rozmowie i wołają się nawzajem przez [`@`](/contracts/mentions/).
  </Card>
</CardGrid>
